**Код к заданию:**
```c++
#include <iostream>
#include <string>
#include <vector>

using namespace std;

class Route {
private:
    string pointA;
    string pointB;
    string pointC;

public:
    Route(const string& a, const string& b, const string& c) 
        : pointA(a), pointB(b), pointC(c) {
        cout << "Точки маршрута заданы" << endl;
    }

    ~Route() {
        cout << "Маршрут удалён" << endl;
    }
};

class Bus {
private:
    int number;
    Route* busRoute;
    static int howManyBuses;

public:
    Bus(int n) : number(n), busRoute(nullptr) {
        howManyBuses++;
        cout << "Автобус с номером " << n << " создан" << endl;
    }

    ~Bus() {
        howManyBuses--;
        cout << "Автобус удалён" << endl;
    }

    void setBusRoute(Route* r) {
        busRoute = r;
    }

    Route* getBusRoute() const {
        return busRoute;
    }
};

class Depot {
private:
    static Depot* instance;
    vector<Bus*> buses;
    static int busesCounter;

    Depot() {}

public:
    Depot(const Depot&) = delete;
    Depot& operator=(const Depot&) = delete;

    static Depot* getInstance() {
        if (instance == nullptr) {
            instance = new Depot();
        }
        return instance;
    }

    void addBus(Bus* b) {
        buses.push_back(b);
    }
};

int Bus::howManyBuses = 0;

Depot* Depot::instance = nullptr;

int main() {
    setlocale(LC_ALL, "ru");
    
    Route route("Макарова", "Юности", "Кулакова");
    Bus bus(101);

    bus.setBusRoute(&route);

    Depot* depot = Depot::getInstance();
    depot->addBus(&bus);

    return 0;
}
```

## Контрольные вопросы
1. Что такое композиция? Приведите пример.
Ответ: Композиция - это отношение часть-целое, где часть не может существовать без целого. Пример: дом и комнаты.

2. Что такое агрегация? Чем она отличается от композиции?
Ответ: Агрегация - это отношение часть-целое-, где часть может существовать независимо от целого. Отличие от композиции в том, что целое не управляет временем жизни части.

3. Как реализовать композицию в C++? Приведите пример кода.
Ответ: Композицию в C++ реализуют через поле-объект, unique_ptr или динамическое выделение с удалением в деструкторе. Пример: `class House { Room livingRoom; };`

4. Как реализовать агрегацию в C++? Приведите пример кода.
Ответ: Агрегацию реализуют через указатели или ссылки на объекты, созданные вне целого. Пример: `class Library { vector<Book*> books; };`

5. В чём разница между временем жизни частей при композиции и агрегации?
Ответ: При композиции часть живёт ровно столько же, сколько целое. При агрегации часть живёт независимо от него.

6. Что такое статическое поле класса? Чем оно отличается от обычного поля?
Ответ: Статическое поле принадлежит всему классу, а не объекту, и существует в единственном экземпляре. Обычное поле есть у каждого объекта своё.

7. Как объявить и определить статическое поле? Где оно хранится?
Ответ: Объявление в классе: `static int count;`, определение вне класса: `int MyClass::count = 0;`. Хранится в статической памяти.

8. Что такое статический метод? Можно ли из него обратиться к нестатическим полям?
Ответ: Статический метод можно вызвать без объекта. Из него нельзя обратиться к нестатическим полям, так как нет this.

9. Для чего используются статические счётчики объектов?
Ответ: Статические счётчики используют для подсчёта созданных объектов: увеличивают в конструкторе, уменьшают в деструкторе.

10. Что такое паттерн «Одиночка» (Singleton)? Для чего он нужен?
Ответ: Одиночка - паттерн, гарантирующий один экземпляр класса. Нужен для общих ресурсов, например логгера или конфигурации.

11. Как запретить создание копий объекта (конструктор копирования)?
Ответ: Запретить копирование можно так: `Singleton(const Singleton&) = delete;` и `operator=` тоже удалить.

12. В каком порядке вызываются конструкторы и деструкторы при композиции?
Ответ: При композиции конструкторы частей вызываются до тела конструктора целого, деструкторы - после тела деструктора целого в обратном порядке.

13. Можно ли изменить статическое поле из обычного метода?
Ответ: Да, из обычного метода можно изменить статическое поле, так как оно принадлежит классу.

14. Почему статические поля нужно определять вне класса?
Ответ: Статические поля нужно определять вне класса, чтобы выделить под них память.

15. В каких случаях стоит использовать композицию, а в каких — агрегацию?
Ответ: Композицию используют, когда часть не может жить без целого. Агрегацию - когда часть независима и может принадлежать разным целым.
